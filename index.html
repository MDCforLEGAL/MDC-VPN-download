Architecture & Security

Two editions. One calm interface.

Each edition talks to a real, native tunnel — no shims, no hidden relays. Profiles and credentials stay on the device, inside the app sandbox.

Android Edition

Kotlin · Material 3 · VpnService

Native app built on Kotlin and Material Design 3. The tunnel runs through Android's own VpnService with the OpenVPN 3 core, in a dedicated process.

  • OpenVPN 3 (OVPN3) core via libovpn3.so, wired into VpnService.
  • Persistent foreground notification with a live chronometer and quick disconnect.
  • State recovery after a process kill — the app verifies the live tunnel, not a cached flag.
  • Private storage with allowBackup=false; imported profiles never leave the sandbox.
libovpn3.so minSdk 24 AGPL-3.0

Windows x64 Edition

Java / Swing · Portable EXE

A lightweight portable desktop app. No installer, no service to manage — double-click MDC-VPN.exe and elevate when Windows asks.

  • Bundled OpenVPN Community with the Wintun driver, plus native WireGuard for Windows.
  • UAC elevation prompt only when the tunnel actually needs it.
  • Temporary credential files are written for the session and cleaned up on disconnect.
  • Single portable folder — run it from a USB stick and remove it without a trace.

Features

Everything the tunnel needs. Nothing else.

Built for teams that maintain their own VPN servers and want a client that stays out of the way.

Multi-protocol support

Import .ovpn (OpenVPN) and .conf (WireGuard) profiles straight from the file picker. No conversion steps and no cloud upload.

One-tap control & live metrics

Connect or disconnect instantly, follow the session duration counter and watch upload and download speeds in real time.

Legacy & enterprise compatibility

Full support for BF-CBC, ns-cert-type, tls-remote, LZO, TLS 1.0 and auth-user-pass — old infrastructure keeps working.

Smart fail-safe & diagnostics

A 45-second connection timeout with plain-language error diagnostics, instead of a spinner that never resolves.

Zero-trace local privacy

Profiles live in a private app sandbox with allowBackup=false. No telemetry, and temporary auth files are deleted on disconnect.

Fully open source (AGPL-3.0)

Transparent automated builds via GitHub Actions — read the source, check the workflow, verify the artifact yourself.
